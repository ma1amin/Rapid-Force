# Compliance Framework Mapping

## NIST
Identify, Protect, Detect, Respond, Recover mapped to modules.

## ISO 27001
Controls mapped to IAM, encryption, logging, governance.

## CIS Controls
Mapped per module (logging, vulnerability, IAM).

## SOC2
Audit logs, access control, monitoring.

## PCI DSS / HIPAA
Data protection, encryption, segmentation.

## CMMC
Maturity model with validation.

## SAMA
Data residency, regulatory reporting.

## COBIT
Governance and process control.
